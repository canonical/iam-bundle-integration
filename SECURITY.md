# Security policy

## Reporting a vulnerability

To report a security issue, file a [Private Security Report][1] with a
description of the issue, the steps you took to create the issue,
affected versions, and, if known, mitigations for the issue.

The [Ubuntu Security disclosure and embargo policy][2] contains more
information about what you can expect when you contact us and what we
expect from you.

[1]: https://github.com/canonical/iam-bundle-integration/security/advisories/new
[2]: https://ubuntu.com/security/disclosure-policy
